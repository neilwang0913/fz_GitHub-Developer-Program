# Legendary Waddle

A small MIT-licensed open-source project.

- Docs / landing page: https://neilwang0913.github.io/fz_GitHub-Developer-Program/
- Usage: `node src/index.js World`

## GitHub API example

`GITHUB_TOKEN=<token> node src/github.js octocat` lists a user's most recently updated repos
(the token is optional for public data but raises rate limits).
